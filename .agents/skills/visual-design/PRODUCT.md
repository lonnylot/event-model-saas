## Unique look

Unique-look proof of `header` / AppBar is GET `/`, `/login`, site-admin `/app`, and editor `header`. Picker / team / Teams admin lead is `<p><a href="/app">Event Model</a></p>` — `header` flex/padding rules do not apply. A follow-up look pass may wrap those leads in `header`. Do not list those screens as AppBar ACs while markup is not `header`.

## Shell

`meta viewport` copied onto login / expired / guest `/app` / `shell` / editor without extra ACs is the look shell those screens mount. Unique proof is GET `/`. Not extra chrome — do not add an AC per HTML file.

## Type token

Google Fonts Inter `@import` + `font-family: Inter, …` vs locked `type` (`ui-sans-serif, system-ui, sans-serif`) and Out of scope “Webfont files” is `need-user`, not look-may-grow type scale. Do not ship the import or Inter prefix until the user restates the token and Out of scope.
