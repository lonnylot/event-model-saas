# Add toolbar selected slice

Status: released

## Problem

Toolbar `Add Command` after clicking the first of two Slices still appends to `slices.at(-1)` and paints `lastLaneList`. The Mac app uses `selection.sliceID` (else last). A member who selects the first Slice and clicks Add Command cannot add a Command to that Slice.

## Acceptance criteria

- [x] After a member creates a model, opens it, clicks `New Slice`, clicks the first `New Slice` listitem in the Slices region, and clicks `Add Command`, the Timeline region of the first Slice shows a listitem whose accessible name is `Command`

## Domain terms

Event Model, Slice, Command, Team, Person, Version

## Seams

- `bindEditor` in `public/editor.js` — toolbar Add Command targets the selected Slice
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## UI

Screens: Editor. Primitives: Page. Look of Editor is `visual-design` ([ADR 0001](../../adr/0001-look-iteration.md)). Inventory: [design-system.md](../design-system.md).

## Assumptions

- Playwright unique checkout `PORT` / `INSPECTOR_PORT` and `TEST_MAIL=1` `workers` `1` stay [public-face.md](./public-face.md).
- Dashed `Add Command on lane` and selected-Slice ⌥⌘2 stay [add-on-lane.md](./add-on-lane.md) / [add-on-lane-rest.md](./add-on-lane-rest.md). Toolbar Add Actor on the selected first of two Slices is [add-toolbar-selected-slice-rest.md](./add-toolbar-selected-slice-rest.md). Toolbar Add Event on the selected first of two Slices is [add-toolbar-selected-slice-rest.md](./add-toolbar-selected-slice-rest.md). Toolbar Add of Read Model / Automation stay later. Toolbar Add Command on the selected first of two Slices is this slice.
- Create model still seeds a default Slice ([model-defaults.md](./model-defaults.md)). Two `New Slice` listitems in the Slices heading list are first vs last. With no Slice selected, toolbar Add Command still targets the last Slice ([blocks.md](./blocks.md)).
- Accessibility bar is WCAG 2.2 AA for contrast of locked token pairs and a visible `:focus-visible` affordance ([ADR 0001](../../adr/0001-look-iteration.md)).
