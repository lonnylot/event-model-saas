# Hydrate add field

Status: released

## Problem

After Save and reload, clicking a GET-rendered Command, Event Happened, Read Model, or Automation shows Field name of a Field that already exists, but Inspector has no `Add Field`, so a member cannot append another Field without adding a new block of that kind first.

## Acceptance criteria

- [x] After a member creates a model, opens it, clicks `Add Command`, clicks the Timeline `Command` listitem, clicks `Add Field`, and Saves, a reload of that page, clicking the Timeline `Command` listitem shows a button whose accessible name is `Add Field` in the Inspector region
- [x] After a member creates a model, opens it, clicks `Add Event`, clicks the Timeline `Event Happened` listitem, clicks `Add Field`, and Saves, a reload of that page, clicking the Timeline `Event Happened` listitem shows a button whose accessible name is `Add Field` in the Inspector region
- [x] After a member creates a model, opens it, clicks `Add Read Model`, clicks the Timeline `Read Model` listitem, clicks `Add Field`, and Saves, a reload of that page, clicking the Timeline `Read Model` listitem shows a button whose accessible name is `Add Field` in the Inspector region
- [x] After a member creates a model, opens it, clicks `Add Automation`, clicks the Timeline `Automation` listitem, clicks `Add Field`, and Saves, a reload of that page, clicking the Timeline `Automation` listitem shows a button whose accessible name is `Add Field` in the Inspector region
