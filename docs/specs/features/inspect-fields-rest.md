# Inspect fields rest

Status: validated

## Problem

Inspector can Add Field on a Command and rename it. Members cannot set Field type, optional, or example, cannot delete a Field, and cannot append a Field on Event, Read Model, or Automation, so the Mac Fields editor is incomplete.

## Acceptance criteria

- [x] After clicking `Add Field` on `Command`, selecting `UUID` in Inspector `Field type` sets the last Command `fields[0].type` to `UUID`
- [ ] After clicking `Add Field` on `Command`, checking Inspector `Optional` sets the last Command `fields[0].optional` to `true`
- [ ] After clicking `Add Field` on `Command`, filling Inspector `Example` with `abc` sets the last Command `fields[0].example` to `abc`
- [ ] After clicking `Add Field` on `Command`, clicking `Delete Field` sets the last Command `fields` to `[]`
- [ ] Clicking `Add Field` after selecting `Event Happened` appends a Field whose `name` is `newField` on the last Event
- [ ] Clicking `Add Field` after selecting `Read Model` appends a Field whose `name` is `newField` on the last Read Model
- [ ] Clicking `Add Field` after selecting `Automation` appends a Field whose `name` is `newField` on the last Automation
- [ ] After clicking `New Slice` then `Add Command` twice, clicking the first Timeline `Command` listitem, clicking `Add Field`, filling `Field name` with `orderId` sets the first Command `fields[0].name` to `orderId`

## Domain terms

Event Model, Slice, Command, Event, Read Model, Automation, Field, Team, Person, Version

## Seams

- `document` module — set Field `type` / `optional` / `example`, delete Field, append Field on Event / Read Model / Automation; the editor path calls it
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## Assumptions

- `Add Field` and Command `newField` / `String` / `Field name` stay [inspect-fields.md](./inspect-fields.md) when that spec is present.
- Field type option labels are the schema enum: `String`, `Boolean`, `Int`, `Long`, `Double`, `Decimal`, `Date`, `DateTime`, `UUID`, `Custom`. Combobox accessible name is `Field type`.
- `Optional` is a checkbox. `Example` is a textbox. `Delete Field` is a button on that Field row.
- Add still targets the last Slice. Field JSON mutates the last of that kind.
- Edits are in-memory until Save.
- The `TEST_MAIL=1` memory adapter does not count login attempts, so Playwright files can share one Worker without the production 5-per-hour cap.

## Out of scope

Actor Fields (Mac has none). Mac window chrome. Command Add Field and Field name stay [inspect-fields.md](./inspect-fields.md). Inspect Fields after reload is [inspect-rest.md](./inspect-rest.md).
