# Inspect fields rest

Status: released

## Problem

Inspector can Add Field on a Command and rename it. Members cannot set Field type, optional, or example, cannot delete a Field, cannot append a Field on Event, Read Model, or Automation, and cannot name or type those Fields, so the Mac Fields editor is incomplete.

## Domain terms

## Seams

- `document` module — set Field `type` / `optional` / `example`, delete Field, append Field on Event / Read Model / Automation, set Field `name` on the clicked Command / Event / Read Model / Automation (`appendField(model, target, id)` / `setFieldName(model, name, id, target)` when `id` is the clicked block); last-Command `appendField(model)` / `setFieldName(model, name)` stay [inspect-fields.md](./inspect-fields.md); the editor path calls it
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## Assumptions

- Last-Command `Add Field` and last-Command `newField` / `String` / Field name stay [inspect-fields.md](./inspect-fields.md) when that spec is present. In-session Delete Field immediately after Add Field stays this file. In-session Delete Field after re-click of a Command that already has a Field is [inspect-in-session-delete-field.md](./inspect-in-session-delete-field.md).
- Field type option labels are the schema enum: `String`, `Boolean`, `Int`, `Long`, `Double`, `Decimal`, `Date`, `DateTime`, `UUID`, `Custom`. Combobox accessible name is `Field type`.
- `Optional` is a checkbox. `Example` is a textbox. `Delete Field` is a button on that Field row.
- Toolbar Add Command on the selected first of two Slices is [add-toolbar-selected-slice.md](./add-toolbar-selected-slice.md). Toolbar Add Actor / Event / Read Model / Automation still targets the last Slice. Add Field on a Command in the first of two Slices is [inspect-add-field-first-slice.md](./inspect-add-field-first-slice.md). Add Field on Event / Read Model / Automation in the first of two Slices stay later. Command Field type / optional / example / delete mutate the last Command. Add Field after selecting Event / Read Model / Automation mutates the last of that kind, including Field name / type / optional / example / delete. After two Commands, Add Field and Field name mutate the clicked Command. After two Events, Add Field and Field name mutate the clicked Event. After two Read Models, Add Field and Field name mutate the clicked Read Model. After two Automations, Add Field and Field name mutate the clicked Automation. After two Commands, Field type / Optional / Example / Delete Field mutate the clicked Command.
- Edits are in-memory until Save.
- The `TEST_MAIL=1` memory adapter does not count login attempts, so Playwright files can share one Worker without the production 5-per-hour cap.
