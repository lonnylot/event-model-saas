# Inspect get automation

Status: released

## Problem

GET `/app/teams/{id}/models/{mid}` after two Automations, clicking `Send Email` (the first) shows Inspector Description `Bill it` (the last Automation). Description binds `processors.at(-1)`, so a member who reopens a model cannot inspect the first Automation's Description.

## Acceptance criteria

- [x] After a member creates a model, opens it, clicks `Add Automation`, clicks the Timeline `Automation` listitem, fills `Name` with `Send Email`, fills `Description` with `When paid`, clicks `Add Automation`, clicks the last Timeline `Automation` listitem, fills `Name` with `Charge Card`, fills `Description` with `Bill it`, and Saves, a reload of that page, clicking the Timeline `Send Email` listitem shows the Inspector `Description` textbox with the value `When paid`

## Domain terms

Event Model, Slice, Automation, Description, Team, Person, Version

## Seams

- `bindInspect` in `public/editor-inspect.js` — GET Automation Description bind by the clicked listitem
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## UI

Screens: Editor. Primitives: Page. Look of Editor is `visual-design` ([ADR 0001](../../adr/0001-look-iteration.md)). Inventory: [design-system.md](../design-system.md).
