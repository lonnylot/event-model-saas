# Inspect get delete field

Status: released

## Problem

GET `/app/teams/{id}/models/{mid}` after Save of a Command Field, clicking `Command` shows Field name but Inspector has no `Delete Field`. GET inspect unbinds the Field row and rebinds name / type / Optional / Example only, so a member who reopens a model cannot delete that Field without adding another Field first.

## Acceptance criteria

- [x] After a member creates a model, opens it, clicks `Add Command`, clicks the Timeline `Command` listitem, clicks `Add Field`, and Saves, a reload of that page, clicking the Timeline `Command` listitem shows a button whose accessible name is `Delete Field` in the Inspector region

## Domain terms

Event Model, Slice, Command, Field, Team, Person, Version

## Seams

- `bindInspect` in `public/editor-inspect.js` — GET Command `Delete Field` after reload
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## UI

Screens: Editor. Primitives: Page. Look of Editor is `visual-design` ([ADR 0001](../../adr/0001-look-iteration.md)). Inventory: [design-system.md](../design-system.md).

## Assumptions

- Playwright unique checkout `PORT` / `INSPECTOR_PORT` and `TEST_MAIL=1` `workers` `1` stay [public-face.md](./public-face.md).
- GET Field of one Command stays [inspect-rest.md](./inspect-rest.md). In-session `Delete Field` stays [inspect-fields-rest.md](./inspect-fields-rest.md). `Add Field` after reload stays [hydrate-add-field.md](./hydrate-add-field.md). Delete Field after reload of one Command is this slice.
- Accessibility bar is WCAG 2.2 AA for contrast of locked token pairs and a visible `:focus-visible` affordance ([ADR 0001](../../adr/0001-look-iteration.md)).
