# Inspect rest

Status: validated

## Problem

Inspector inspects Command → Event and Name after reload. Members cannot inspect Event → Read Model, reopen Description / Slice type / Fields after Save, inspect a GET-rendered Connection, or reopen Description and Fields on the other kinds, so those edits do not round-trip like Name.

## Domain terms

Event Model, Slice, Actor, Command, Event, Read Model, Automation, Connection, Field, Slice type, Description, Team, Person, Version

## Seams

- `document` module — set Slice / Actor / Command / Event / Read Model / Automation `description`, Slice `sliceType` / `title`, Event Model `title`, append Field, set Field `name`, set Field `type`, set Field `optional`, and set Field `example` on an in-memory Event Model; the editor click, fill, and select path calls it
- `handleRequest` — model page HTML hydrates Timeline Connection text and Slice / heading listitems so Inspector binds after GET
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## Assumptions

- Command → Event inspect From/To on a click-created Connection stays [inspect-connection.md](./inspect-connection.md) when that spec is present. Event → Read Model summary text is `Event Happened → Read Model` (Add defaults). GET-rendered Connection summary text is `Command → Event Happened` or `Event Happened → Read Model`.
- Description / Type / Field / Connection / Slice Name / heading Name after reload is a click on the GET-rendered listitem or heading, same as [inspect-after-reload.md](./inspect-after-reload.md) for Name. Field type / Optional / Example after reload is a click on that GET-rendered listitem.
- Delete Connection is Backspace ([delete-blocks.md](./delete-blocks.md)). No extra Inspector delete button.
- Heading click to open model Inspector stays [model-inspector.md](./model-inspector.md) when that spec is present. This slice owns the click after reload. No ⇧⌘I.
- Add Field on Event / Read Model / Automation appends `newField` ([inspect-fields.md](./inspect-fields.md) / [inspect-fields-rest.md](./inspect-fields-rest.md) when present). This slice owns the Field name after reload inspect.
- The `TEST_MAIL=1` memory adapter does not count login attempts, so Playwright files can share one Worker without the production 5-per-hour cap.

## Out of scope

Mac inspector captions (naming hints, Slice type help). Mac Model Info ⇧⌘I. Inspector Delete Connection button. Model inspector counts, connection roster, and format line. Extra zoom percentages. Mac window chrome (`NSDocument`, native menus, welcome window). Click-created Command → Event inspect, in-session heading-click model inspect, Name after reload on Actor / Command / Event / Read Model / Automation, Optional / Example after reload on Event / Read Model / Automation, and Backspace delete Connection stay those specs.
