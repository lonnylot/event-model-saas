# Inspect rest

Status: released

## Problem

Inspector inspects Command → Event and Name after reload. Members cannot inspect Event → Read Model, reopen Description / Slice type / Fields after Save, inspect a GET-rendered Connection, or reopen Description and Fields on the other kinds, so those edits do not round-trip like Name.

## Domain terms

Event Model, Slice, Actor, Command, Event, Read Model, Automation, Connection, Field, Slice type, Description, Team, Person, Version

## Seams

- `document` module — set Slice / Actor / Command / Event / Read Model / Automation `description`, Slice `sliceType` / `title`, Event Model `title`, set Field `name`, set Field `type`, set Field `optional`, and set Field `example` on an in-memory Event Model; the editor click, fill, and select path calls it
- `handleRequest` — model page HTML hydrates Timeline Connection text and Slice / heading listitems so Inspector binds after GET
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## Assumptions

- Command → Event inspect From/To on a click-created Connection stays [inspect-connection.md](./inspect-connection.md) when that spec is present. Event → Read Model summary text is `Event Happened → Read Model` (Add defaults). GET-rendered Connection summary text is `Command → Event Happened` or `Event Happened → Read Model`. Clicking Timeline text `Command → Event Happened` still opens Inspector From/To. That node living in `.board` is [connection-on-board.md](./connection-on-board.md). Clicking Timeline text `Event Happened → Read Model` still opens Inspector From/To. That node living in `.board` is that slice. GET `data-id` on that node and Backspace on that GET node are [hydrate-connection-id.md](./hydrate-connection-id.md).
- Description / Type / Field / Connection / Slice Name / heading Name after reload is a click on the GET-rendered listitem or heading, same as [inspect-blocks.md](./inspect-blocks.md) / [chrome.md](./chrome.md) for Name. Field type / Optional / Example after reload is a click on that GET-rendered listitem. GET after Create hydrates Timeline `New Slice` as well as the sidebar listitem ([hydrate-board.md](./hydrate-board.md)). Clicking `Checkout` after reload uses the first matching listitem. A unique `Checkout` listitem is leftover unused.
- In-session Delete Connection is Backspace ([delete-blocks.md](./delete-blocks.md)). GET Connection Backspace is [hydrate-connection-id.md](./hydrate-connection-id.md). No extra Inspector delete button.
- Heading click to open model Inspector stays [model-inspector.md](./model-inspector.md) when that spec is present. This slice owns the click after reload. No ⇧⌘I.
- Add Field that appends `newField` on Event / Read Model / Automation stays [inspect-fields-rest.md](./inspect-fields-rest.md). This slice owns the Field name after reload inspect. `Add Field` after reload is [hydrate-add-field.md](./hydrate-add-field.md).
- The `TEST_MAIL=1` memory adapter does not count login attempts, so Playwright files can share one Worker without the production 5-per-hour cap.

## Out of scope

That node living in `.board` is [connection-on-board.md](./connection-on-board.md). Mac inspector captions (naming hints, Slice type help). Mac Model Info ⇧⌘I. Inspector Delete Connection button. Model inspector counts, connection roster, and format line. Extra zoom percentages. Mac window chrome (`NSDocument`, native menus, welcome window). Click-created Command → Event inspect is [inspect-connection.md](./inspect-connection.md). Name after reload on Actor / Command / Event / Read Model / Automation is [inspect-after-reload.md](./inspect-after-reload.md). In-session heading-click model inspect, Optional / Example after reload on Event / Read Model / Automation, and in-session Backspace delete Connection stay those specs. GET Connection Backspace is [hydrate-connection-id.md](./hydrate-connection-id.md). Leftover Type after clicking `Event Happened → Read Model`, leftover From Event Happened and leftover To Read Model after a later click on `Command → Event Happened` is [inspect-switch.md](./inspect-switch.md).
