# Inspect rest

Status: validated

## Problem

Inspector inspects Command → Event and Name after reload. Members cannot inspect Event → Read Model, or reopen Description, Slice type, and Fields after Save, so those edits do not round-trip like Name.

## Acceptance criteria

- [x] After dragging from `Event Happened port` onto `Read Model port`, clicking the Timeline text `Event Happened → Read Model` shows the text `From Event Happened` in the Inspector region
- [x] After dragging from `Event Happened port` onto `Read Model port`, clicking the Timeline text `Event Happened → Read Model` shows the text `To Read Model` in the Inspector region
- [x] After a member creates a model, opens it, clicks `New Slice`, clicks `Add Command`, clicks the Timeline `Command` listitem, fills `Description` with `Customer submits cart`, and Saves, a reload of that page, clicking the Timeline `Command` listitem shows the Inspector `Description` textbox with the value `Customer submits cart`
- [ ] After a member creates a model, opens it, clicks `New Slice`, clicks the `New Slice` listitem, selects `State View` in `Type`, and Saves, a reload of that page, clicking the `New Slice` listitem shows Inspector `Type` with the value `State View`
- [ ] After a member creates a model, opens it, clicks `New Slice`, clicks `Add Command`, clicks the Timeline `Command` listitem, clicks `Add Field`, fills `Field name` with `orderId`, and Saves, a reload of that page, clicking the Timeline `Command` listitem shows Inspector `Field name` with the value `orderId`

## Domain terms

Event Model, Slice, Command, Event, Read Model, Connection, Field, Slice type, Description, Team, Person, Version

## Seams

- `document` module — set Command `description` on an in-memory Event Model; the editor click and fill path calls it
- Browser — Playwright against `wrangler dev` with `TEST_MAIL=1`

## Assumptions

- Command → Event inspect From/To stays [inspect-connection.md](./inspect-connection.md) when that spec is present. Event → Read Model summary text is `Event Happened → Read Model` (Add defaults).
- Description / Type / Field after reload is a click on the GET-rendered listitem, same as [inspect-after-reload.md](./inspect-after-reload.md) for Name.
- Delete Connection is Backspace ([delete-blocks.md](./delete-blocks.md)). No extra Inspector delete button.
- Model title and Description stay heading-click ([model-inspector.md](./model-inspector.md)). No ⇧⌘I.
- The `TEST_MAIL=1` memory adapter does not count login attempts, so Playwright files can share one Worker without the production 5-per-hour cap.

## Out of scope

Mac inspector captions (naming hints, Slice type help). Mac Model Info ⇧⌘I. Inspector Delete Connection button. Model inspector counts, connection roster, and format line. Extra zoom percentages. Mac window chrome (`NSDocument`, native menus, welcome window). Command → Event inspect, heading-click model inspect, Name after reload, and Backspace delete Connection stay those specs.
